    What this verifies
    Runs Taste Skill's real lint.mjs rules and scan loop live; only Node file reading is swapped for in-memory input. Fully offline, no model calls. It verifies static source checks, not AI design, the real browser inspector or the full design process; passing the scan does not make a page look better.
